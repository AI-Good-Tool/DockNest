DockNest 2.7.0：为 macOS 程序坞打造的原生应用文件夹。

- 独立多开：多个文件夹同时运行，各有 Dock 图标、应用列表和设置。
- 自由改名：保留身份和数据，同步显示在窗口、Finder 与 Dock。
- 拖拽整理：拖入应用、按住图标移动排序、边缘自动滚动。
- 搜索启动、静态缩略图、JSON 备份与恢复、独立登录自启动。
- 新增「关于 DockNest」，提供仓库、作者和手动检查更新。

下载 `DockNest-2.7.0-macOS-arm64.dmg`，将 `DockFolder.app` 拖入「应用程序」。仅支持 Apple Silicon（arm64），需要 macOS 26 或更新版本。已有多开入口请在「管理多开文件夹」中更新。

安装包使用 ad-hoc 签名，未经过 Apple Developer ID 公证。安装包不包含个人应用列表。
